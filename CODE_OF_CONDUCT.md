# Bitmasters Community Netiquette & Server Conduct

Bitmasters operates on the spirit of the early 2000s PC gaming era. We believe in raw competition, intense firefights, banter, and minimal moderation. We do not maintain a sanitized corporate environment, nor do we act as referees for personal disagreements. 

If you played games during the GameSpy, IRC, and dedicated server era, you already know how this works. If you are new, read the rules below.

---

### 1. Thick Skin Required
This is a competitive, tactical military shooter from 2003. Expect trash talk, rivalries, teasing, and aggressive playstyles. If someone kills you through smoke, camps a ladder, or insults your aim in global chat, use your weapons to answer them—do not open a GitHub issue or demand administrative intervention over banter. 

### 2. Zero Tolerance for Infrastructure Sabotage
The only actions that will result in an immediate network-wide ban are those targeting the stability of the servers or the safety of players:
- **No Malicious Network Attacks:** Do not send malformed UDP packets, flood servers with ghost bots, attempt DDoS attacks, or exploit unpatched memory vulnerabilities against server hosts.
- **No Malicious Injections:** Using memory trainers, speedhacks, wallhacks, or modified binaries on protected public servers will earn you an instant permanent ban.
- **No Doxxing or Real-Life Harassment:** Keep the fight inside the game. Posting real-world personal information (names, phone numbers, physical addresses, private contact details) or making threats against someone outside the game will get you purged immediately.

### 3. Server Autonomy
Independent server hosts run their servers however they see fit. If a server operator wants a sniper-only rule, a no-knife rule, or kicks you because they don't like your handle, that is their prerogative. Bitmasters provides the engine patch and the master network routing; individual server owners hold the banhammer on their own nodes. If you don't like how someone runs their server, forward your ports and launch your own.

### 4. Developer Issues Are for Code, Not Drama
The GitHub repository is an engineering tracker for the BitPatch binary, crash logs, and reverse-engineering documentation. 
- Open tickets for bugs, reproducible crash logs, and engine incompatibilities.
- Tickets opened to complain about player disputes, clan drama, or in-game arguments will be closed and locked immediately.

Play the objective, watch your corners, and have fun.
