# Security Policy

## Supported Versions

We actively monitor and patch security vulnerabilities for the current main release of the BitPatch client and server architecture. 

| Version | Supported          |
| ------- | ------------------ |
| BIT-1.0 | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, exploit, or cheat bypass within the BitPatch infrastructure, please **DO NOT** open a public GitHub issue. 

Instead, report it directly to the Bitmasters administration team:
1. Reach out to server staff securely via the official [Bitmasters Discord](https://discord.gg/dvwcbGVeyV).
2. Detail the steps to reproduce the exploit.

We take security seriously and will work to issue a hotfix as quickly as possible.
